
# Language Comparison

## Python
- Simple and readable
- Less code
- Good for beginners

## JavaScript
- Runs in browser and Node.js
- Asynchronous capabilities
- Slightly more complex input handling

## C
- Fast and efficient
- Requires manual memory handling
- More verbose

## Java
- Object-oriented
- Strongly typed
- More structured and verbose

## Summary
| Language   | Ease of Use | Performance | Readability |
|-----------|------------|------------|------------|
| Python    | High       | Medium     | High       |
| JavaScript| Medium     | Medium     | Medium     |
| C         | Low        | High       | Low        |
| Java      | Medium     | High       | Medium     |
